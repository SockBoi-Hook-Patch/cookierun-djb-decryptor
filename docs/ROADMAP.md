# Roadmap

| Version | Scope | Exit criteria |
|---|---|---|
| 0.2.0 | Core stabilization | bounded parsing, strict verification states, packaging, baseline tests |
| 0.3.0 | Parser upgrade | broader record fixtures, malformed-input corpus, JSON schema decisions |
| 0.4.0 | Forge upgrade | Gen1/Gen2 raw writer round-trips; FastLZ encoder only after reference vectors |
| 0.5.0 | CLI upgrade | stable info/decrypt/batch/forge UX, safe paths, structured errors |
| 0.6.0 | Test engineering | genuine Gen1 + Gen2 fixtures, differential tests, fuzzing |
| 0.7.0 | Documentation | format confidence labels, Thai and English guides, provenance review |
| 0.8.0 | CI/CD | multi-Python CI, release workflow, reproducible packages |
| 1.0.0 | Stable | genuine Gen1 and Gen2 validation plus game-loader compatibility evidence |

No version is considered game-loader compatible solely because synthetic tests pass.
